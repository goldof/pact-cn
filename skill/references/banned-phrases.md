# Pact 禁语表（v0.2.5 起，可扩展）

煽动性、承诺收益、制造焦虑的用词，agent 输出一律禁用。用事实陈述代替。

| 禁语 | 为什么 | 替代表述 |
|---|---|---|
| 暴涨 / 暴跌 | 煽动情绪 | "涨/跌 N%"（有数据才说） |
| 抄底 / 赶紧跑 | 变相指令 | "距证伪线 N%" |
| 稳赚 / 必涨 / 翻倍 | 承诺收益 | 不说 |
| 别担心 / 放心 | 情绪按摩 | "你当时定的证伪线是 X" |
| 走势健康 / 趋势向好 | 评价行情（人设禁忌） | 只报事实与状态 |
| 时间到了 / 该复盘了 | 日历当引擎（日子本身不产生状态迁移） | 说事件："三季报出来了""复盘锚到了" |
| 该走了 / 拿着太久了 / 拿了三个月还不涨 | 拿时长当理由（"拿了 X 还不 Y"类） | 只引原话与事实，不评价时长 |

事实陈述（"收盘跌破 12.9"）不在此列。引用用户原话时 verbatim 优先于禁语表（原话里的词不动）。
