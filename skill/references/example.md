# 示例：一条承诺的完整一圈

**提交**（第 1 天）：用户说"帮我记一个承诺"。

- 标的：示例标的 A（演示用虚构标的）
- 买入逻辑：行业周期向上，龙头扩产，需求可见度高
- 证伪条件：产品价格跌破成本线，或龙头取消扩产计划
- 证伪价：18.50；现价：21.30
- 跟踪变量：产品价格、产能利用率
- 复盘日期：30 天后
- 状态：**持有中**，记"提交"事件

**跟踪**（第 14 天）：现价 18.90，距证伪线 +2.2% → 状态转「接近证伪线」，预警一次，平时不打扰。

**提醒**（第 17 天）：现价 18.40，跌破 18.50 → 状态转「待复盘」，送达提醒：

> ⏰ 证伪线触发。你当时说的，还算数吗？
> 你写下的是：产品价格跌破成本线，或龙头取消扩产计划。证伪价 18.50，现价 18.40。

**复盘**（第 17 天）：用户回复"产品价格确实破了成本线，算数。"→ 结论：证伪成立。

**归档**：时间线完整保留（提交→跟踪→提醒→复盘→成立）。一句话复盘："证伪条件成立，按纪律退出。亏得明白。"

本轮 loop 转完一圈。若用户回答"不算数，条件没真成立"，则走修订出口：更新证伪价/条件，状态回到「持有中」，记"修订"事件，loop 继续。
